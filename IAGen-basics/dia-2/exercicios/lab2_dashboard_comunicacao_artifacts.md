# Laboratório 2: Dashboard Visual em Claude Artifacts e Comunicação Multi-Canal

**Contexto:** Um único fato em obra reverbera em diferentes públicos: diretoria, equipe técnica de campo e subempreiteiros.
**Objetivo:** Usar o Claude Artifacts para construir um dashboard visual interativo e derivar comunicações personalizadas para múltiplos canais.

---

## 🛠️ O Desafio

1. **Dashboard Executivo com Claude Artifacts:**
   - Solicite ao Claude a geração de um **Artifact HTML/Tailwind interativo** representando o Painel de Controle Semanal da Obra Alpha Tower.
   - O painel deve conter:
     - Cards de KPI: % de Conclusão Global, Saldo Orçamentário e Pontuação de Segurança.
     - Barra de progresso visual das frentes de serviço (Fundação, Estrutura, Alvenaria, Acabamento).
     - Alerta crítico em vermelho para o atraso no fornecimento de aço de 10mm.
2. **Diagrama de Fluxo em Mermaid (Artifact):**
   - Peça a criação de um diagrama Mermaid ilustrando o fluxo de liberação de concretagem: *Armação $\rightarrow$ Verificação pelo Fiscal $\rightarrow$ Liberação para Usina $\rightarrow$ Slump Test $\rightarrow$ Concretagem $\rightarrow$ Corpos de Prova $\rightarrow$ Cura/Desforma*.
3. **Comunicação em Cascata:**
   - Redija:
     - Uma apresentação de 3 slides (Markdown / Google Slides) para o comitê semanal.
     - Um e-mail formal de alinhamento com a diretoria da usina de concreto exigindo pontualidade.
     - Uma mensagem direta e objetiva para o WhatsApp do mestre de obras.

# Checklist de Preparação - IAGen-basics

Guia prático para instrutores e participantes garantirem um ambiente 100% operacional antes do início do curso.

---

## 💻 Requisitos para os Participantes

### 1. Acesso às Ferramentas de IA
- [ ] **Conta Google ativa** com acesso ao **Gemini** ([gemini.google.com](https://gemini.google.com)).
- [ ] **Conta Anthropic ativa** com acesso ao **Claude** ([claude.ai](https://claude.ai)) com a funcionalidade de **Artifacts** habilitada nas configurações de perfil.
- [ ] *(Opcional / Recomendado)*: Acesso ao ChatGPT ([chatgpt.com](https://chatgpt.com)) para comparações de resposta.

### 2. Acesso a Ferramentas de Escritório
- [ ] Acesso a um navegador moderno (Chrome, Edge ou Brave atualizados).
- [ ] Acesso ao Google Drive com permissão para criar Google Docs, Google Sheets e Google Slides.
- [ ] Conexão de internet estável para chamadas e streaming de telas.

---

## 👨‍🏫 Checklist do Instrutor

- [ ] Clonar e revisar todos os arquivos do repositório `IAGen-basics`.
- [ ] Verificar se os arquivos de dados simulados em `dia-1/dados/`, `dia-2/dados/` e `dia-3/dados/` estão acessíveis.
- [ ] Testar os prompts do guia com antecedência nos modelos mais recentes (Claude 3.5 Sonnet / Gemini 1.5 Pro / 2.0).
- [ ] Ter links encurtados ou pasta compartilhada no Drive com os arquivos de dados para envio rápido aos participantes caso necessário.
- [ ] Preparar ambiente de demonstração com abas pré-carregadas.
